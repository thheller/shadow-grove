shadow-grove examples

Every concept of shadow-grove, explained next to a live demo and the code that runs it. Each page is built from its example's source file in src/dev/examples/, so the text, the code and the demo can't drift apart. A browser scenario in examples/test/scenarios/ checks what the text says. See examples/README.md.
